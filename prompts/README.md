# Prompt log

This folder documents how I directed AI during the build. Each file covers one step and follows the same format, so the reasoning behind each decision is visible, not only the final result.

## Format of each file

    # <step number> — <step name>

    ## Goal
    What I needed from this step and why.

    ## Prompt
    The prompt as I sent it, with personal or sensitive details replaced by [brackets].

    ## What came back
    A short summary of the output.

    ## What I kept, changed or rejected
    The decisions I made on the output and the criteria behind them.

## Steps

| File | Step |
|---|---|
| 01-discovery.md | Framing the problem and the users |
| 02-content.md | Selecting the essential and most-asked information |
| 03-build.md | First build |
| 04-iterations.md | Corrections and refinements |

Files are added as each step is documented.
